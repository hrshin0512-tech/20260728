# 로또 추첨기

웹에서 바로 열어 사용할 수 있는 6/45 로또 추첨기입니다.

## 실행

1. `index.html`을 브라우저에서 직접 엽니다.
2. 또는 폴더를 간단한 정적 서버로 띄워서 확인합니다.

## 기능

- 1부터 45까지의 번호 중 6개 추첨
- 보너스 번호 자동 생성
- 추첨 애니메이션
- 최근 결과 5개 저장

## 서버(옵션): OpenAI 연동

로컬에서 OpenAI `gpt-5.4-mini` 모델을 사용해 번호 설명을 생성하려면 간단한 프록시 서버를 실행하세요.

1. `.env.example` 파일을 복사하여 `.env`를 만들고 `OPENAI_API_KEY`를 설정합니다.

```
cp .env.example .env
# 편집: OPENAI_API_KEY=sk-...
```

2. 의존성 설치 및 서버 실행

```bash
npm install
npm start
```

3. 브라우저에서 `index.html`을 연 뒤 챗봇에서 생년월일을 입력하면 서버가 OpenAI에 요청하여 설명을 생성합니다. 서버가 없으면 클라이언트 로컬 규칙으로 동작합니다.

참고: API 키는 절대 클라이언트 코드에 직접 넣지 마십시오. 서버에서 환경변수로 관리해야 합니다.
